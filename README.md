# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

The **HR Analytics Dashboard** is an interactive data visualization project built using Microsoft Power BI to analyze employee data, workforce distribution, and employee attrition.

The dashboard provides meaningful insights into employee demographics, departmental performance, salary slabs, job satisfaction, and attrition trends. It helps HR professionals understand workforce patterns and make data-driven decisions to improve employee retention and organizational performance.

## 🎯 Project Objectives

- Analyze overall employee strength and active employees.
- Monitor employee attrition count and attrition rate.
- Understand employee distribution across different departments.
- Analyze attrition based on salary slabs and job roles.
- Explore employee demographics, including age and gender.
- Identify patterns in attrition based on employee experience.
- Provide an interactive dashboard for HR decision-making.

## 📊 Dashboard Visualizations

The dashboard includes the following visualizations:

1. **Attrition by Department** – Analyzes employee attrition across departments such as Administration, Operations, Sales, IT, Marketing, Human Resources, and Finance.

2. **Attrition by Salary Slab** – Examines attrition across different salary categories to identify salary-related workforce patterns.

3. **Attrition by Job Role & Job Satisfaction** – Provides a breakdown of employee attrition across job roles and job satisfaction ratings.

4. **Age Group Distribution** – Displays employee distribution across different age groups (18–25, 26–35, 36–45, 46–55, and 55+).

5. **Attrition by Gender** – Compares employee attrition between male and female employees.

6. **Attrition Trend by Experience** – Visualizes how attrition varies with employee experience.

7. **Department-wise Employee Count** – Compares employee distribution across different departments.

## 🎛️ Interactive Features

- **Department Filter:** Filter dashboard insights by individual departments.
- **Age Group Filter:** Analyze employee data across different age categories.
- **Dynamic Visualizations:** Charts and KPIs respond to selected filters.
- **Cross-Filtering:** Explore relationships between different dashboard visuals.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data transformation and cleaning.
- **DAX (Data Analysis Expressions)** – KPI calculations and analytical measures.
- **Data Modeling** – Organizing employee data for reporting and analysis.
